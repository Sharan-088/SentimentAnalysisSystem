================================================================================
STEP 2: INSTALL DEPENDENCIES
================================================================================
Once virtual environment is activated, run:

    pip install -r requirements.txt

This will install:
- nltk (3.8.1) - Natural Language Toolkit
- textblob (0.17.1) - Text processing
- scikit-learn (1.3.2) - Machine learning models
- pandas (2.1.1) - Data manipulation
- numpy (1.24.3) - Numerical operations

Installation time: ~2-3 minutes

================================================================================
STEP 3: RUN THE APPLICATION
================================================================================
Execute the main program:

    python main.py

This opens the interactive menu system.

================================================================================
EXECUTION WORKFLOW - FIRST TIME
================================================================================

1. SELECT OPTION 4: Create Dataset
   - Creates sample sentiment data
   - Saves to dataset.csv
   - Shows distribution (5 positive, 5 negative, 5 neutral)

2. SELECT OPTION 1: Train Models
   - Loads dataset.csv
   - Preprocesses text (cleaning, tokenization, stemming)
   - Vectorizes text using TF-IDF
   - Trains 3 models: Logistic Regression, SVM, Naive Bayes
   - Evaluates models with metrics
   - Saves models as .pkl files
   - Duration: ~30-60 seconds

3. SELECT OPTION 2 or 3: Predict Sentiment
   - Option 2: Interactive mode - type text and get predictions
   - Option 3: Test with predefined samples
   - Shows sentiment (positive/negative/neutral) with confidence

4. SELECT OPTION 5: Exit
   - Closes the application

================================================================================
WHAT EACH FILE DOES
================================================================================

data_collection.py
  - Creates sample dataset with 15 labeled texts
  - Run directly: python data_collection.py
  
preprocessing.py
  - Handles text cleaning and preprocessing
  - Removes URLs, special chars, stopwords
  - Performs tokenization and stemming
  - Run directly: python preprocessing.py (shows examples)

model_training.py
  - Trains three ML models
  - Evaluates using accuracy, precision, recall, F1-score
  - Saves models to .pkl files
  - Run directly: python model_training.py

sentiment_predictor.py
  - Loads saved models for predictions
  - Makes sentiment predictions on new text
  - Run directly: python sentiment_predictor.py (test examples)

main.py
  - Interactive command-line interface
  - Main entry point - use this to run the system
  - Provides menu system for all operations

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "ModuleNotFoundError: No module named 'nltk'"
Solution: Run "pip install -r requirements.txt"

Problem: "FileNotFoundError: dataset.csv not found"
Solution: Run Option 4 (Create Dataset) first

Problem: "FileNotFoundError: logistic_regression_model.pkl"
Solution: Run Option 1 (Train Models) first

Problem: Virtual environment not activating
Solution: 
  - Ensure you're in the correct directory
  - Use full path: C:\path\to\venv\Scripts\activate.ps1
  - On PowerShell, may need to run: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned

Problem: Slow performance during training
Solution: This is normal for small datasets. With larger datasets it will be slower.

================================================================================
CUSTOMIZATION OPTIONS
================================================================================

To use more data:
1. Edit data_collection.py
2. Add more text samples to the 'data' dictionary
3. Increase samples for each sentiment class
4. Run the system again

To change the model used for predictions:
1. Edit sentiment_predictor.py line: predictor = SentimentPredictor(model_name='logistic_regression')
2. Change 'logistic_regression' to 'svm' or 'naive_bayes'

To adjust preprocessing:
1. Edit preprocessing.py
2. Modify the TextPreprocessor class methods
3. Run training again with new preprocessing
